# Music-mobile-application-prototype
A figma file for a prototype for a music mobile application which uses AI to generate curated playlists for users suffering from mental health issues to reduce decision paralysis found in traditional music applications. It takes user inputs on their mood and what genre they'd like to listen to and then generates an appropriate playlist to help alleviate their symptoms. It is a high fideltiy walkthrough and evry button has a function so it feels as if you are using the application. Just press the play icon in the top right corner. Try it out!
